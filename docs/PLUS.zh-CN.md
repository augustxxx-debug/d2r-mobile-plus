# Plus 构建与验证说明

[English](PLUS.md) · [项目概览](../README.zh-CN.md) · [更新日志](../CHANGELOG.zh-CN.md)

## 范围与原理

Plus 修改兼容层及构建时的 UI 生成器，不改写输入的原始游戏文件。构建期间，生成器读取玩家自己的资源，在被忽略的构建目录中生成覆盖层和打包资源。应用将这些生成资源与原版游戏数据配合使用。

前端场景覆盖与界面坐标分别处理。底部控件根据可用屏幕几何布局；保留游戏内原有坐标打包方式。布局覆盖限定在触控／手柄根节点，不对所有共享面板进行整体改写。

两类右下角标志分别处理：多图层火焰字样与红色存档标志。先在隐藏状态下初始化位置，再显示，避免加载切换时先出现一帧尚未定位的图像。

### 任务语音行为

基线版本的运行消息区分任务选择、语音播放和对话结束。快速第二次点击会发出结束事件。原地按住 0.8 秒后松手没有产生点击，因为移动触控识别器拒绝达到或超过普通 0.35 秒点击时限的操作。

Plus 仅允许原版／资料片任务日志根节点下的任务图标、重播控件和关闭目标使用更慢的原地松手。语音状态仍由游戏处理。拖动、取消、物品交互和无关按钮保留原有手势规则。结论来自修改前后的实机消息对照，并非独立零售版 Switch 对照测试。

## 可选字体

此功能为实验功能，仅在设置 `DM_UI_FONT` 时启用。请自行提供有权使用的静态 TrueType 字体。仓库不包含 ARKai_T，也尚未验证其实际显示效果。

在资源生成所用的同一个 Python 环境中安装可选依赖：

```sh
python3 -m pip install -r dm/ios/tools/requirements-fonts.txt
export DM_UI_FONT='/path/to/your/font.ttf'
cd dm/ios
./run.sh build
```

将变量传给构建进程，或写入私有构建环境。不要提交字体或本机配置。取消 `DM_UI_FONT` 后，构建使用原字体，并清理旧的可选字体产物。

生成器统一每 em 单位，保留原版纵向度量和注册名称，并从原游戏字体补齐缺失的 Unicode 字符。不覆盖输入文件。更换字体内容会通过指纹使已生成文字失效并重建。产物位于被忽略的 `Gen/assets/UIFonts` 及生成的资源覆盖层中。

覆盖范围：共享的 `BlizzardGlobal-V5_81.ttf` 字体、使用该字体生成的文字及原生秘境 HUD 字体加载器。其他装饰字体、经典位图文字和烘焙在游戏图片中的文字不在此次范围内。保留纵向度量不保证字宽相同；实际字体仍需在中英文和不同屏幕布局下检查换行、回退字形及裁切。

合成字体测试覆盖 Unicode 缺字回退、每 em 单位转换、原版注册名称／纵向度量、输入文件不变、内容指纹、关闭后清理及无效路径。它们不能证明 ARKai_T 的视觉效果正确。

## 验证

验证记录：**2026-10-25**，上游基线 `195ae11dc70f1ba7735c6063e1ed81102e1dbf52`。

| 检查 | 结果／覆盖范围 |
|---|---|
| iOS 触控识别器 | 49 个用例、4,487 项检查通过，包括慢速任务点击及取消／拖动保护 |
| 宿主 UI 分类 | 381 项检查通过 |
| 前端几何 | 44 项检查通过 |
| 通知生成器 | 边框生成自动化检查通过 |
| 字体合成 | 3 个合成字体测试通过；目标字体待验证 |
| 实机构建 | 签名 iOS 构建成功 |
| 任务问题复现 | 基线慢速松手无效；修改后慢速和快速松手均停止语音 |
| 加载标志连续截图 | 已检查此前布局构建的 44 张截图 |
| 私有原生绑定夹具 | 跳过三项依赖夹具的测试；夹具不随仓库分发 |

在仓库根目录、启用工作区环境后执行相关检查：

```sh
python3 dm/i18n/scan_literals.py
python3 dm/ios/tools/dm_i18n.py --check
python3 dm/host/tests/native_write_scan.py dm/host --selftest
make -C dm/ios/tests test
python3 dm/ios/tests/test_font_override.py
make -C dm/host/tests build/t_minimap_lift build/t_uiscreen_frontend
./dm/host/tests/build/t_minimap_lift
./dm/host/tests/build/t_uiscreen_frontend
```

字体测试在缺少可选依赖时明确跳过。部分更广泛的测试需要游戏衍生表或私有运行夹具，参见[贡献要求](../CONTRIBUTING.zh-CN.md)。本预览未声称完成全部改写等价性、整套图形测试或零售 Switch 真值验收。Plus 补丁未修改改写器和图形引擎。

## 发布卫生

仅发布源码和文档。生成资源、字体、存档、设备截图、私有诊断、签名配置和密钥保留在公开目录之外。推送前检查新增提交的文件内容及作者／提交者元数据。提交问题反馈前先检查本地诊断是否含个人信息。

`main` 保留上游基线，`codex/plus` 包含增强预览。如需对照，请在自己的工作区构建相应分支。先备份存档；不要卸载持有唯一存档副本的应用。
